# Pick Up - App Overview

## Konsep
Pick Up adalah aplikasi on-demand service (mirip Gojek) yang menyediakan layanan transportasi, pengiriman barang, dan jasa lainnya. Fokus utama: **clean, modern, solid white, user-friendly**.

## Target Platform
- **Primary**: iOS & Android (Flutter)
- **Future**: Web dashboard (admin/merchant)

## Brand Identity
- **Nama**: Pick Up
- **Tagline**: "Siap Antar, Siap Jemput"
- **Personality**: Bersih, cepat, terpercaya, modern

## Design Principles
1. **Clean Look** - Minimalis, banyak whitespace, tanpa clutter
2. **Solid White** - Background putih dominan, accent color hijau (#00C853) untuk CTA
3. **Modern** - Rounded corners, subtle shadows, smooth animations
4. **User-Friendly** - Navigasi intuitif, max 3 tap untuk aksi utama

## Typography
- **Font**: SF Pro (iOS) / Roboto (Android) - system default
- **Heading 1**: 28sp, Bold
- **Heading 2**: 22sp, SemiBold
- **Heading 3**: 18sp, SemiBold
- **Body**: 16sp, Regular
- **Caption**: 14sp, Regular
- **Small**: 12sp, Regular

## Icon Style
- Outlined icons (bukan filled) untuk kesan clean
- Stroke width: 1.5-2px
- Warna mengikuti text color atau primary color untuk active state
