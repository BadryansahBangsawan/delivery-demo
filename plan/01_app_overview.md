# DELIVRY - App Overview

## Konsep
DELIVRY adalah super app mobility & on-demand services yang menyediakan layanan transportasi, pengiriman barang, pesan makanan, dan jasa lainnya. Fokus utama: **modern, cepat, premium, user-friendly**.

## Target Platform
- **Primary**: iOS & Android (React Native + Expo)
- **Future**: Web dashboard (admin/merchant)

## Brand Identity
- **Nama**: DELIVRY
- **Tagline**: "Move Anything Anytime"
- **Personality**: Modern, cepat, tegas, terpercaya, premium
- **Visual**: Ungu (Purple) → premium + tech + trust

## Design Principles
1. **Premium Clean** — Minimalis, banyak whitespace, accent ungu memberikan kesan premium
2. **Solid White** — Background putih dominan, accent color ungu (#7B2FF2) untuk CTA
3. **Modern** — Rounded corners, subtle shadows, smooth animations
4. **User-Friendly** — Navigasi intuitif, max 3 tap untuk aksi utama
5. **Speed First** — UI terasa ringan, transisi cepat, loading states yang baik

## Icon Style
- Outlined icons (bukan filled) untuk kesan clean
- Stroke width: 1.5-2px
- Warna mengikuti text color atau primary color untuk active state
- Recommended icon set: Lucide Icons (modern, consistent, React Native support)
